See how your answer was made, a cleaner composer, and web search that is yours.

## What's new

- **See the steps behind an answer.** When a local model thinks, uses a tool or searches the web, the steps appear as a short trail above its reply &mdash; what it thought about, what it searched for, and when it read the results. The trail is saved with the conversation, so it is still there when you come back.
- **A calmer composer.** The message box holds just four things: attach, microphone, token count and send. Thinking and Tools moved into the model menu, next to the model they belong to, and Templates moved into the main menu under Conversation.
- **Web search uses your own free Tavily key.** If you used web search before, open the model menu and choose *Set up web search* &mdash; it takes about a minute, and Tavily's free plan includes 1,000 searches a month. Until a key is added, web search stays off. Settings shows your saved key, how many searches are left this month, and when it was last checked.
- **Safer for kids.** In Kids Mode, Stop and Esc work while an answer is being prepared, a stopped answer is never shown half-finished, and a message about being in crisis always shows the hotline information. Asking for a new answer no longer leaves two answers behind.

## Fixes

- The Qwen 3.8 27B Balanced model downloads again (it failed with a download error).
- X-Ray's Performance History records your local replies and refreshes each time you open it.
- A new app icon.
