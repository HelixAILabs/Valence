Also new: a living background, printing for parents, a safer updater, and smaller fixes.

**A recovery key for your parental password.** If you forget your parental password, a recovery key lets you set a new one.
- To create one: open Parent Dashboard &gt; Controls and choose Create key next to Recovery key. Valence also asks when it starts, and before you add a child.
- Save the key as a file on a USB stick, or keep it in a note on your phone, not on this computer. Valence asks you to type it back once, to check your copy.
- If you forget the password: on the password screen choose Forgot Password?, open your key file or note, type the key, then choose a new password. Each key works once, and Valence gives you a new one when you use it.
- No key yet, but you set a security question? In a child's profile, Forgot Password? now offers your question, then gives you a key. Parent Dashboard &gt; Controls shows the date it was used.

**A living background.** Ripple is a quiet dot grid behind the conversation that ripples out from the message box. It is on by default. To change it, open Settings &gt; Theme &gt; Background &gt; Living background:
- Choose Ripple or None.
- Intensity sets how bright the dots are.
- Motion smoothness goes from Calm (15 fps) to Very smooth (60 fps). Smoother motion uses more graphics power; Balanced (20 fps) is the default.
- Turning off Glow & motion effects holds Ripple still.

**Links in Kids chats stay closed.** When a child clicks, middle-clicks or presses Enter on a link, nothing is opened or downloaded, and a short notice says the link was blocked. When a link is clicked, or pressed after the pointer rests on it, the browser may still open a connection to that site. "Save link as" is gone from the right-click menu in Kids profiles. Dragging a link onto a Kids chat shows the same notice, and dropping a link into the message box types its address.

**Print a child's conversation.** In the parent console, a transcript can be printed again. The console locks itself after 5 minutes without activity, and an open print window closes when it locks.

**Updates are checked before they install.** Valence installs an update only if the file matches the version it just checked, and checks the file again when you click Install now.

**See update progress in Settings.** Settings &gt; About shows the download progress under Check for Updates, and an Install now button when it's ready.

## Fixes
- Qwen3 models now turn thinking off when you choose that.
- If your computer can't run a model, the reason now shows, and a failed hardware scan says "Couldn't check".
- In Kids setup, a model download no longer shows another download's progress.
- The built-in GPU packs show their size on disk, and an unknown pack is refused.
- In local-only mode, the web search key isn't checked online.
- Forgot Password? no longer offers a recovery code that can't work, and any problem shows inside the password window.
- Kids setup no longer asks for a security question. The recovery key replaces it.
- In Kids profiles for children under 10, the main button now stays purple when you point at it, instead of changing to the theme's hover color. Profiles for older children, or with no age set, keep the theme color.
- In a Kids chat, when the AI sends back no answer, or fails partway through a reply, your child now sees a short "I don't have an answer for that one" line instead of an empty reply.
- If you change a child's age while their profile is open, the colors and the message box hint now match the new age.
- Links to files on this PC (file: links) in chats no longer open, in any profile.
- With a Windows high-contrast theme, the main button in the parental password window now has a visible outline.
- In Kids chats, everyday phrases such as "spend it all" no longer set off a crisis alert.
- If you switch tabs while a Kids reply is still loading, crisis help now appears in the tab where the message was sent.
- Links written with a bracketed address, such as https://[::1], now show as plain text and don't open.
- In Settings &gt; Theme &gt; Motion, the Streaming Reveal choices and the Replay button are readable on dark themes.
